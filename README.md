# 📚 About CS-Labs-UI

**CS-Labs-UI** is a full-stack educational platform developed for **GATE Computer Science** aspirants. It provides an engaging learning experience through mock examinations, study materials, progress analytics, and a clean modern interface powered by **React** and **Django REST Framework**.

> 🎓 Learn • Practice • Analyze • Succeed

# 🚀 Installation

### React Frontend

```bash
npm install
npm start
```

### Django Backend

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
